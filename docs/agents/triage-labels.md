# Triage 标签

技能以五个标准 triage 角色为语言。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| 技能中的标签 | 本跟踪器中的标签 | 含义 |
| ------------ | ---------------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整,可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色(如"应用 AFK-ready triage 标签")时,使用表中对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
